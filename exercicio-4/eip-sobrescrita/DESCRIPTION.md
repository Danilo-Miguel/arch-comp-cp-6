<h2 align="center">Reconheça o valor que chegou ao EIP</h2>

> Alvo didático local de 32 bits. Não o exponha como serviço de rede.
> Você só pode errar uma vez; o segundo erro invalida este desafio.

O objetivo desta primeira prática é interpretar o registrador de instrução
após uma entrada controlada no laboratório. Em uma execução de demonstração,
o debugger mostra:

```text
eip  0x42424242
```

Registre exatamente esse valor hexadecimal em `/home/hacker/resposta-4.txt`.
O desafio trata de reconhecer o dado observado, não de executar código em um
endereço arbitrário.

```bash
/challenge/check
```
